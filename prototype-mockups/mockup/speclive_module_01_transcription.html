The export preserves session_id, segment_id, speaker_id, start_ms, end_ms, text, is_final, origin and revision. These are stable interface boundaries, not a claim that the browser provides precise diarization or word offsets.

Next integration step: Feed these finalized transcription events into F04, where they can be joined with F02 speaker segments by timestamp. Do not run the requirements extractor over uncommitted partial text; corrections or hypotheses generated from partial speech are especially unstable.
No account · no JavaScript libraries · no remote API keys embedded · outputs downloaded locally. This is a proof-of-interface, not the planned Parakeet/Whisper inference service.
