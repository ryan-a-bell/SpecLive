Embed on GitHub Pages

Put these HTML files together in the same folder on your published branch. GitHub Pages can serve the hub at index.html, while each prototype also has its own shareable URL. To embed F08 in a different page on the same site:

<iframe src="speclive_module_08_validation.html" title="SpecLive F08"
        width="100%" height="850" allow="microphone"></iframe>

Important: browser microphone permissions require HTTPS or localhost; an iframe may need additional microphone permissions. This static demonstration stores its processing state in the browser only. Live ASR, production diarization, and LLM semantic inference require provider adapters or back-end services. F05/F06 local analysis uses rules and lightweight text similarity. F07 scores represent transparent ranking heuristics, not a calibrated measure of confidence or information gain.
